01
INTRODUCE YOURSELF

我的个人名片

入门 · HTML / CSS+

做一张能在浏览器打开的自我介绍卡，展示你的爱好、技能与学习目标。

核心功能

头像与简介、技能标签、作品链接、移动端布局。

实践路线

先写标题与段落 → 用 Flexbox 排版 → 加入悬停效果 → 在手机尺寸检查。

加一点挑战

添加深色模式切换，并用 localStorage 记住选择。

02
A LITTLE INSPIRATION

每日灵感生成器

入门 · JavaScript+

点击按钮随机获得一句鼓励自己的话，把喜欢的灵感留下来。

核心功能

名言数组、随机切换、主题筛选、收藏列表。

实践路线

准备数组 → 用 Math.random() 选取 → 更新 DOM → 避免连续重复。

加一点挑战

加入关键词搜索，支持复制当前名言。

03
BUILD YOUR ROUTINE

七天习惯打卡

进阶 · 数据存储+

给阅读、运动或编程设定一个七天小目标，让进步变得看得见。

核心功能

添加习惯、每日完成状态、进度条、本地保存。

实践路线

画出七天网格 → 绑定点击 → 计算完成率 → 保存 JSON 数据。

加一点挑战

支持撤销打卡与新一周重置。

04
TRAIN YOUR SUPER MEMORY

英雄记忆翻牌

进阶 · 游戏逻辑+

将四位英雄藏在八张卡牌后，用记忆找到相同的两张。

核心功能

洗牌、翻牌、配对判断、计时与最佳成绩。

实践路线

复制角色数组 → Fisher–Yates 洗牌 → 保存两次选择 → 判断胜利。

站内示例

体验已经完成的翻牌游戏 ↗

05
FOCUS ON ONE THING

专注学习计时器

进阶 · 时间管理+

用一段专注时间完成一项小任务，再给自己一个短暂休息。

核心功能

25 分钟倒计时、开始/暂停、重置、完成提示。

实践路线

设计时间显示 → 使用截止时间计算 → 区分暂停与重置 → 更新状态。

加一点挑战

自定义专注时长，记录当天完成的次数。

06
COLLECT YOUR CURIOSITY

我的兴趣图鉴

入门 · 网格布局+

为喜爱的角色、书籍或电影建立小图鉴，让每张卡片都有自己的故事。

核心功能

卡片网格、分类按钮、关键词搜索、详情展示。

实践路线

整理条目 → CSS Grid 排列 → data 属性分类 → JavaScript 过滤。

加一点挑战

加入排序功能，并完善图片替代文字。

Projects

These are six small projects I thought of while learning HTML, CSS, and JavaScript. I want to start with the basic features and improve them as I learn.

My project ideas

  1. Personal introduction page

    Build a small online profile to share my interests, skills, and learning goals.

    • Content: a profile picture, introduction, interests, and links to my work.
    • Practice: HTML headings, paragraphs, images, links, and simple CSS layouts.

  2. Daily quote generator

    Click a button for a random quote and save the ones I like.

    • Features: random quotes, topic filters, keyword search, and favorites.
    • Practice: JavaScript arrays, random numbers, and DOM updates.

    Example on this website: visit the quotes page.

  3. Seven-day habit tracker

    Set a small reading, exercise, or coding goal and track a week of progress.

    • Features: add habits, mark each day complete, show progress, and save locally.
    • Practice: click events, working with dates, and localStorage.

  4. Hero memory match

    Hide four characters behind eight cards and turn them over to find matching pairs.

    • Features: shuffled cards, matching pairs, a timer, move count, and personal best.
    • Practice: shuffling arrays, managing game state, and using conditions.

    This project is ready to try: play memory match.

  5. Study focus timer

    Focus on one task for 25 minutes, then get a reminder to take a break.

    • Features: a countdown, start, pause, reset, and a completion message.
    • Practice: calculating time, using timers, and handling button clicks.

  6. My interests gallery

    Collect favorite characters, films, or books in a small gallery and explain why I recommend them.

    • Features: an image gallery, category filters, keyword search, and descriptions.
    • Practice: CSS Grid layouts, organizing data, and filtering lists.

I hope to build these ideas one by one and use Git to record each change.
